## ✨ What team-formation Does

Student team formation can become messy when many students choose projects, staff need to balance teams, and everyone expects a fair result. team-formation brings the process into one repeatable workflow.

The application uses a staff Excel workbook as the main planning file. Staff enter students, projects, team sizes, and priority rules into the workbook. The solver then assigns every student to a project team while respecting the rules you set. When the assignment is complete, team-formation creates an audit report that explains how the result was produced.

The result is a team list that is consistent, easy to review, and backed by a solver that proves the assignment is optimal under the stated rules. In plain terms, it gives you the best possible team arrangement for the priorities and limits you entered.

## 🧠 How It Works

The process is built around a few clear stages:

1. Staff prepare the Excel workbook with student records, project choices, team limits, and priority rules.
2. Student preference data can come from Google Forms or Microsoft Forms and be added to the workbook.
3. The solver reads the workbook and checks the available team combinations.
4. Every student is assigned to a project team.
5. Strict priorities are applied first, so important rules are not traded away for convenience.
6. The audit report records the assignment and the rule decisions behind it.
7. Staff review the team list and share the final results.

The solver is an OR-Tools CP-SAT solver. You do not need to understand constraint programming to use it. The application handles the technical work while staff focus on the rules, projects, and student preferences.

## 🛠️ Preparing Your Workbook

Before your first run, take a few minutes to prepare the staff Excel workbook. A little care here makes the final team list much easier to read and share.

- List every student exactly once, using the same naming format throughout.
- List every project with a clear name and any limits on team size.
- Record the priority rules in plain language so staff can review them later.
- Add student preferences from your Google Forms or Microsoft Forms export.
- Check that no student has been left out of the student list.
- Keep a copy of the workbook before each run so you can compare results.

If you run team formation several times, keep each workbook and each audit report together. That way you can show how a final team list was reached and answer questions from students or colleagues.

## 🧾 Reviewing the Audit Report

The audit report is there to remove guesswork. After a run, open the report and check that:

- Every student appears in exactly one team.
- Team sizes match the limits you set.
- Strict priority rules were respected.
- Any trade-offs are explained in plain language.
- The final team list matches the assignment in the report.

If something does not look right, adjust the priority rules in the workbook, run the process again, and compare the new audit report with the previous one.
